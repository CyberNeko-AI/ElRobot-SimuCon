## 3. 总线更新率推算

Feetech STS 半双工协议，写一次位置 ≈ 9–10 字节：

- @ 1 Mbps（8N1，10 bit/字节）：9×10 = 90 bit → **~90 µs/次写入**
- 同步读回 ACK（~6 字节）≈ 60 µs → 单舵机一次「写+确认」≈ **150 µs**
- 8 舵机串联逐写：8×150 µs ≈ **1.2 ms**，加半双工换向间隙 → **一轮 ~1.5–3 ms**
- → 总线理论更新率 **~300–700 Hz**；实际瓶颈是上位机软件回路（Python 100–200 Hz）与舵机内部 PID 回路
- 仿真建议：控制回路 100–200 Hz + 目标位置 **1–5 ms 一阶延迟**

## 4. 待测项（标定方法）

### 4.1 舵机内建 PID 参数 / 等效带宽（`SERVO_KP`、`SERVO_DAMPING`）

当前仿真用 `position` 执行器近似：`kp=200 N·m/rad`、`damping=0.5 N·m·s/rad`
（`build_mjcf.py` 中 `SERVO_KP` / `SERVO_DAMPING`）。这两个值**不是实测值**。

**标定方法**：给舵机一个阶跃目标（如 0°→30°，空载），记录位置-时间曲线，
读出上升时间 / 超调量 / 振荡频率，然后用仿真里的 `kp`+`damping` 去拟合同一
阶跃响应，即可得到等效刚度与阻尼。等效一阶带宽 ≈ 该阶跃响应的时间常数。

### 4.2 位置刚度（`kp`，决定「带载垂头」）

**标定方法**：在末端（或关节输出轴）挂已知负载，测输出轴偏转角 θ。
`kp = 施加力矩 / θ`。当前仿真 kp=200 在 0.49 N·m 标定负载下偏转约 0.14°。

### 4.3 控制器死区（deadband）

当前仿真用 `DEADBAND_DEG = 0.5°`（`controller.py`），**只包含了齿轮虚位**；
控制器自身的死区未知。实测后把两者相加填入 `DEADBAND_DEG`。

**标定方法**：缓慢增大目标角度，记录「目标变化多少度后，输出才开始动」——
这个阈值就是控制器死区；齿轮虚位单独测（固定电机、手摇输出轴测空行程）。

### 4.4 接触摩擦（夹持用，碰撞几何完成后测）

**标定方法**：打印一块平板，用夹爪夹持已知质量物体，测打滑临界力 → 摩擦系数。
填入被抓物 / 夹爪 `<geom friction>`（当前全局默认 0.4）。

### 4.5 反射惯量（`armature`）

当前用估算值 **0.02 kg·m²**（≈ `J_rotor × 345²`，转子惯量取 ~1.7×10⁻⁷ kg·m²）。

**标定方法**：空载阶跃到最大速度，记录加速段斜率；角加速度 = 堵转扭矩 /
（`J_arm + J_ref`），由此反推 `J_ref`。或直接测量转子惯量后乘 345²。

## 5. 回差/死区的仿真建模说明

真实「垂头」≈ 齿轮回差 + 控制器死区 + 位置刚度下垂。仿真已在
`controller.ServoController` 中实现：

1. **速率钳位**：参考位置以 ≤5 rad/s 逼近目标；
2. **死区**：`|参考 − 实际| ≤ 死区` 时输出零力矩（等效回差+控制器死区的自由
   间隙），超过死区后才施加 `kp×(误差−死区)` 的恢复力矩；
3. 稳定下垂量 ≈ `死区 + 重力力矩/kp`（当前 ≈ 0.5° + 0.15° ≈ 0.65°）。
